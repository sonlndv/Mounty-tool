# Mounty-tool listing/source status

**Mounty-tool** is the optional plugin product. Current source: https://github.com/sonlndv/Mounty-tool . Versioned runtime files use the [0.5.0 release](https://github.com/sonlndv/Mounty-tool/releases/tag/0.5.0) when published. The repository was renamed in place; history/releases remain.

Official plugin submission/account linking is maintainer-owned and pending. GitHub publication is not directory acceptance or live activation.

Technical ID/folder remains **omarchy-writing**, with existing settings/hotkeys.
Root main.js/styles.css are directly loadable CommonJS/CSS; no dependencies or
build/transpiler step. Minimum metadata1.5.0 remains inherited. New non-public
Graph interop is validated by shape and exercised in synthetic native1.14.5 desktop QA, not a claim
of all-version or physical-phone/detached/IME/sync support.

## Copyable current plugin description

> Organize one note at a time with graph categories and preview native Graph colours. Keep optional Zen, typewriter and writing controls.

Long description:

> Mounty-tool provides manually assigned, one-property graph categories with
> editable dark/light colours, preview/explicit Apply to native GLOBAL Graph,
> and exact unedited-rule undo. It preserves foreign Groups/non-group options.
> Assign/Clear changes only one pinned Markdown note's mounty-graph property via
> Obsidian's public frontmatter API; no bulk edits, auto-classification or scans.
> Retained optional Zen/typewriter/width/title/follow controls keep their defaults
> and stable IDs. Graph interop is non-public, narrowly validated on native1.14.5
> shapes, with unsupported versions failing closed. Offline: no network, telemetry,
> shell, dependency installers or runtime account. Directory submission remains pending.

No-account/offline runtime is separate from the owner's Obsidian/GitHub account
needed to submit/claim entries. Declared minimum version is not freshly certified.
Source changes do not edit community owner fields or prove approval.

## Theme relationship

Mounty is standalone CSS appearance. Omarchy is a supported equal route with
byte-identical CSS at matching releases; users do not need a theme rename or
this tool for the design. The graph tool also works without replacing a theme.
No theme registry/repository or other plugin configuration is changed here.
